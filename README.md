# Smart Task Management System

## Project Overview

Smart Task Management System is a Flask-based web application that allows users to manage tasks efficiently.

The project includes:

- User Authentication
- REST APIs
- PostgreSQL Database
- Analytics using Pandas & NumPy
- WebSocket Notifications
- Responsive Frontend UI

---

## Technologies Used

- Python
- Flask
- PostgreSQL
- SQLAlchemy
- Pandas
- NumPy
- Flask-SocketIO
- HTML
- CSS

---

## Features

### Authentication
- User Registration
- User Login

### Task Management
- Add Task
- Update Task
- Delete Task
- Get All Tasks

### Analytics
- Total Tasks
- Completed Tasks
- Pending Tasks
- Completion Percentage

### WebSocket
- Real-time task update notifications
